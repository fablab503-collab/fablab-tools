Install guideGuide d'installation

Install Bouclier, step by stepInstaller Bouclier, pas à pas

Bouclier is one app that adds an extension to Safari. You install the app, then switch the extension on in Safari. It takes about two minutes on each device. Bouclier est une app qui ajoute une extension à Safari. Vous installez l'app, puis vous activez l'extension dans Safari. Comptez environ deux minutes par appareil.

  • iPhoneiOS 26 or lateriOS 26 ou plus récent
  • iPadiPadOS 26 or lateriPadOS 26 ou plus récent
  • MacmacOS 26 or latermacOS 26 ou plus récent

Bientôt sur l'App Store. Bouclier n'est pas encore sur l'App Store. Le lien sera ajouté ici le jour de la sortie. Un seul achat couvrira votre iPhone, iPad et Mac. Pour l'essayer avant, voir Avant la sortie sur l'App Store.

iPhone

Safari extensions on iPhone are switched on in the Settings app, not in Safari.Sur iPhone, les extensions Safari s'activent dans l'app Réglages, pas dans Safari.

  1. Get the appTéléchargez l'app

    Open the App Store, search for Bouclier and tap Get (or the price).

    Ouvrez l'App Store, cherchez Bouclier et touchez Obtenir (ou le prix).

  2. Open Bouclier onceOuvrez Bouclier une fois

    Tap the Bouclier icon on your Home Screen. The app shows whether the extension is on and repeats the next steps. You don't need to keep it open.

    Touchez l'icône Bouclier sur l'écran d'accueil. L'app indique si l'extension est activée et rappelle les étapes suivantes. Inutile de la laisser ouverte.

  3. Go to Safari's extensionsAllez dans les extensions de Safari

    Open Settings → Apps → Safari → Extensions.

    Ouvrez Réglages → Apps → Safari → Extensions.

  4. Turn Bouclier onActivez Bouclier

    Tap Bouclier and turn on the Allow Extension switch.

    Touchez Bouclier et activez l'interrupteur Autoriser l'extension.

  5. Allow it on all websitesAutorisez-le sur tous les sites

    On the same screen, under Permissions, set All Websites to Allow.

    Sur le même écran, sous Autorisations, réglez Tous les sites web sur Autoriser.

    Ads and trackers are blocked even without this. With it, Bouclier also hides empty ad spaces, closes pop-up ads and removes video ads.

    Les pubs et traqueurs sont bloqués même sans cela. Avec, Bouclier masque aussi les espaces vides, ferme les pop-up et retire les publicités vidéo.

  6. Optional: Private BrowsingOption : navigation privée

    Still on the same screen, turn on Allow in Private Browsing to block ads in private tabs as well.

    Toujours sur le même écran, activez Autoriser en navigation privée pour bloquer aussi les pubs dans les onglets privés.

  7. Use it in SafariUtilisez-le dans Safari

    Open any website in Safari. Tap the page menu button at the left of the address bar, then tap Bouclier. You'll see what was blocked on the page, and you can pause a site, allow one address or hide an element.

    Ouvrez un site dans Safari. Touchez le bouton du menu de la page, à gauche de la barre d'adresse, puis Bouclier. Vous y voyez ce qui a été bloqué, et pouvez mettre un site en pause, autoriser une adresse ou masquer un élément.

    If Safari asks for permission the first time, choose Always Allow on Every Website.

    Si Safari demande une autorisation la première fois, choisissez Toujours autoriser sur tous les sites web.

iPad

The same as iPhone. If you bought Bouclier on another device with the same Apple Account, it's already paid for here.Comme sur iPhone. Si vous avez acheté Bouclier sur un autre appareil avec le même compte Apple, il est déjà payé ici.

  1. Get the appTéléchargez l'app

    In the App Store, search for Bouclier and tap Get, or the cloud icon if you already own it.

    Dans l'App Store, cherchez Bouclier et touchez Obtenir, ou le nuage si vous l'avez déjà acheté.

  2. Open Bouclier onceOuvrez Bouclier une fois

    Tap its icon on the Home Screen, then go back to the Home Screen.

    Touchez son icône sur l'écran d'accueil, puis revenez à l'écran d'accueil.

  3. Turn Bouclier onActivez Bouclier

    Open Settings → Apps → Safari → Extensions → Bouclier and turn on Allow Extension.

    Ouvrez Réglages → Apps → Safari → Extensions → Bouclier et activez Autoriser l'extension.

  4. Allow it on all websitesAutorisez-le sur tous les sites

    Set All Websites to Allow. Turn on Allow in Private Browsing too if you use private tabs.

    Réglez Tous les sites web sur Autoriser. Activez aussi Autoriser en navigation privée si vous utilisez les onglets privés.

  5. Use it in SafariUtilisez-le dans Safari

    In Safari, tap the page menu button in the address bar, then Bouclier. To hide something on a page, choose Hide an element and tap the thing you want gone.

    Dans Safari, touchez le bouton du menu de la page dans la barre d'adresse, puis Bouclier. Pour masquer quelque chose, choisissez Hide an element et touchez l'élément à faire disparaître.

Mac (Safari extension)Mac (extension Safari)

On the Mac, the extension is switched on in Safari's own settings.Sur Mac, l'extension s'active dans les réglages de Safari.

  1. Get the appTéléchargez l'app

    Open the App Store on your Mac, search for Bouclier and click Get. It installs in your Applications folder.

    Ouvrez l'App Store sur votre Mac, cherchez Bouclier et cliquez sur Obtenir. L'app s'installe dans le dossier Applications.

  2. Open Bouclier onceOuvrez Bouclier une fois

    Open it from Launchpad or the Applications folder. Safari only lists the extension after the app has been opened once. Click Quit and Open Safari Settings… to jump to the next step.

    Ouvrez-la depuis le Launchpad ou le dossier Applications. Safari n'affiche l'extension qu'après une première ouverture. Cliquez sur Quit and Open Safari Settings… pour passer directement à l'étape suivante.

  3. Tick BouclierCochez Bouclier

    In Safari, choose Safari → Settings… → Extensions (or press ⌘ ,), then tick the box next to Bouclier.

    Dans Safari, choisissez Safari → Réglages… → Extensions (ou ⌘ ,), puis cochez la case à côté de Bouclier.

  4. Allow it on all websitesAutorisez-le sur tous les sites

    With Bouclier selected, click Edit Websites… and set Other websites to Allow. If Safari asks instead, click Always Allow on Every Website.

    Bouclier sélectionné, cliquez sur Modifier les sites web… et réglez Autres sites web sur Autoriser. Si Safari vous le demande, cliquez sur Toujours autoriser sur tous les sites web.

  5. Optional: Private BrowsingOption : navigation privée

    In the same Extensions pane, tick Allow in Private Browsing.

    Dans le même panneau Extensions, cochez Autoriser en navigation privée.

  6. Use the toolbar buttonUtilisez le bouton de la barre d'outils

    Bouclier's shield appears in Safari's toolbar. Click it to see what was blocked, pause a site or hide an element. You can also right-click anything on a page and choose Hide This Element….

    Le bouclier de Bouclier apparaît dans la barre d'outils de Safari. Cliquez dessus pour voir ce qui a été bloqué, mettre un site en pause ou masquer un élément. Vous pouvez aussi faire un clic droit sur un élément et choisir Hide This Element….

    Shortcuts: ⌥⇧B opens Bouclier, ⌥⇧P pauses the site, ⌥⇧H hides an element. Don't see the shield? Choose View → Customize Toolbar… and drag it in.

    Raccourcis : ⌥⇧B ouvre Bouclier, ⌥⇧P met le site en pause, ⌥⇧H masque un élément. Pas de bouclier ? Choisissez Présentation → Personnaliser la barre d'outils… et faites-le glisser.

Check that it worksVérifier que ça marche

  1. Open Bouclier's menu in Safari and choose the setup check. Anything marked with an orange dot needs one tap or click from you.

    Ouvrez le menu de Bouclier dans Safari et lancez la vérification de l'installation. Tout ce qui a un point orange demande une action de votre part.

  2. Open the independent test page adblock.turtlecute.org. Expect about two thirds blocked: many of its addresses are only used by phone and TV apps, so web ad blockers leave them alone.

    Ouvrez la page de test indépendante adblock.turtlecute.org. Attendez-vous à environ deux tiers de blocage : beaucoup de ses adresses ne servent qu'aux apps de téléphone et de TV, que les bloqueurs web laissent passer.

If something's wrongEn cas de problème

Bouclier isn't in the Extensions listBouclier n'est pas dans la liste des extensions

Open the Bouclier app once, then close Settings (or quit Safari on the Mac) and look again. On a Mac, check the app is in the Applications folder, not still in Downloads.

Ouvrez une fois l'app Bouclier, puis fermez Réglages (ou quittez Safari sur Mac) et regardez à nouveau. Sur Mac, vérifiez que l'app est dans le dossier Applications et pas dans Téléchargements.

Ads still show on some pagesDes pubs apparaissent encore

Check that All Websites (iPhone, iPad) or Other websites (Mac) is set to Allow, then reload the page. Make sure the site isn't paused in Bouclier's menu.

Vérifiez que Tous les sites web (iPhone, iPad) ou Autres sites web (Mac) est sur Autoriser, puis rechargez la page. Vérifiez aussi que le site n'est pas en pause dans le menu de Bouclier.

A website doesn't workUn site ne fonctionne plus

Open Bouclier's menu on that page and turn the site off, or pause it for an hour. Or tap one of the blocked addresses listed there to allow only that address on that site.

Ouvrez le menu de Bouclier sur cette page et désactivez le site, ou mettez-le en pause une heure. Ou touchez une des adresses bloquées affichées pour l'autoriser sur ce site uniquement.

I hid something by mistakeJ'ai masqué quelque chose par erreur

Open Bouclier's menu on that site and choose Show them again.

Ouvrez le menu de Bouclier sur ce site et choisissez Show them again.

Before the App Store releaseAvant la sortie sur l'App Store

Until Bouclier is on the App Store, you can run it from its source code, which is free and on GitHub. This is meant for people comfortable with developer tools.En attendant l'App Store, vous pouvez utiliser Bouclier depuis son code source, libre et sur GitHub. C'est destiné aux personnes à l'aise avec les outils de développement.

Mac, quick try without XcodeMac, essai rapide sans Xcode

  1. Download the source from GitHub (Code → Download ZIP) and unzip it.

    Téléchargez le code depuis GitHub (Code → Download ZIP) et décompressez-le.

  2. In Safari: Settings → Advanced, tick Show features for web developers.

    Dans Safari : Réglages → Avancés, cochez Afficher les fonctionnalités pour les développeurs web.

  3. Open the new Developer tab, click Add Temporary Extension… and choose the bouclier/extension folder. Then allow it on all websites as in the Mac steps above.

    Ouvrez le nouvel onglet Développeur, cliquez sur Ajouter une extension temporaire… et choisissez le dossier bouclier/extension. Autorisez-la ensuite sur tous les sites comme dans les étapes Mac ci-dessus.

    Safari removes a temporary extension when it quits, so you'll need to add it again next time.

    Safari retire une extension temporaire quand il quitte : il faudra l'ajouter de nouveau la fois suivante.

iPhone, iPad and a permanent Mac appiPhone, iPad et app Mac permanente

  1. You need a Mac with Xcode 26 or later, signed in with your Apple Account in Xcode → Settings → Accounts.

    Il faut un Mac avec Xcode 26 ou plus récent, connecté à votre compte Apple dans Xcode → Réglages → Comptes.

  2. In Terminal, in the bouclier folder, run ./build.sh for the Mac app, or ./build.sh --sim to try the iPhone and iPad app in the Simulator. The README has the details.

    Dans le Terminal, dans le dossier bouclier, lancez ./build.sh pour l'app Mac, ou ./build.sh --sim pour essayer l'app iPhone et iPad dans le Simulateur. Le README donne les détails.

  3. To put it on your own iPhone or iPad, connect it by cable, choose it as the run destination in Xcode and press Run. Then follow the iPhone or iPad steps above from step 2. With a free Apple Account, the app stops opening after 7 days and has to be installed again.

    Pour l'installer sur votre iPhone ou iPad, branchez-le par câble, choisissez-le comme destination dans Xcode et lancez l'exécution. Suivez ensuite les étapes iPhone ou iPad ci-dessus à partir de l'étape 2. Avec un compte Apple gratuit, l'app cesse de s'ouvrir après 7 jours et doit être réinstallée.
